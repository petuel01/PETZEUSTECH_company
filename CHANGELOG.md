# Changelog

All notable changes to the PETZEUSTECH platform will be documented in this file.

## [1.0.0] - 2026-09-13
### Added
- **Visual Design System**: Implemented the official WHITE PETZEUSTECH visual blueprint: clean white canvas, deep navy text, electric blue action buttons, and controlled purple/cyan accent accents.
- **Frontend Core**: Created React 19 + TypeScript single-page application with accessible client-side routing, responsive navbar, mobile drawer, and multi-department layout.
- **Backend Core**: Created full-stack Express server (`server.ts`) with persistent JSON database engine (`/data/db.json`) and complete RESTful `/api` endpoints.
- **Commercial Scoping**: Established honest commercial representations for all 6 departments (Software Labs, CloudCore, Graphics, Electronics, Ads, IT Academy).
- **Booking Engine**: Implemented full booking submission, reference generator (`PTZ-YYYYMMDD-XXXX`), status workflow, and safe WhatsApp message generator.
- **Authentication**: Built 3-method authentication system: Google Identity OAuth, Email/Password with verification, and GitHub OAuth, plus clear explanation for users.
- **Customer System**: Implemented client dashboard for viewing active bookings, profile information, and service history.
- **Admin System**: Built full admin management console with booking review, status transitions, department toggling, project CMS, blog publisher, contact inbox, and audit logs.
- **ZeusAI Diagnostic Assistant**: Integrated Gemini server-side AI consultation to help visitors scope projects and troubleshoot technology issues.
- **Documentation**: Delivered README.md, ARCHITECTURE.md, DECISIONS.md, SETUP.md, SECURITY.md, DEPLOYMENT.md, ROADMAP.md, and `schema.sql`.
